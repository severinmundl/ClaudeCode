# my_gutschein

Projekt für die Wayfinder-Planung von MyGutschein. Noch kein Code; zuerst wird per `/wayfinder` der Weg zum Ziel als Karte aus Entscheidungs-Tickets gezeichnet.

## Agent skills

### Issue tracker

Issues und Wayfinder-Karten liegen als Markdown-Dateien unter `.scratch/<effort>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Standard-Vokabular (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: ein `GLOSSARY.md` plus `docs/adr/` im Projekt-Root (werden lazy von `/domain-modeling` angelegt). See `docs/agents/domain.md`.
